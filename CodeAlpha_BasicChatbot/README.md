CodeAlpha_BasicChatbot 🤖


This repository contains a Basic Chatbot developed as part of my Python Development Internship at CodeAlpha. The project focuses on building a rule-based conversational agent using fundamental Python programming concepts.


📋 Project Overview


The goal of this project was to create a chatbot capable of processing user input and providing predefined responses based on specific keywords. It serves as a practical application of basic Natural Language Processing (NLP) logic and control flow.



🚀 Key Features


Pattern Recognition: Uses if-elif logic to match user messages with appropriate replies.

Input Normalization: Converts all user input to lowercase using .lower() to ensure the bot is case-insensitive.

Continuous Interaction: Utilizes a while True loop to keep the conversation active until the user types "bye".

Predefined Responses: Includes programmed answers for greetings, identity queries, and status checks.

🛠️ Concepts Used


Functions: To encapsulate the response logic.

Conditional Statements: For decision-making based on user input.

Loops: To manage the execution flow of the chat session.

Standard I/O: For capturing user messages and displaying bot replies.
